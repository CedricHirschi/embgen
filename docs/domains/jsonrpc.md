# JSON-RPC Domain

The JSON-RPC domain generates code from JSON-RPC method definitions, typically used for building client-side wrappers around JSON-RPC APIs.

## YAML Schema

```yaml
name: string              # Required: Name for the method set
file: string              # Optional: Output filename (defaults to lowercase name)
prefix: string            # Optional: Prefix string (default: "")
methods:                  # Required: List of methods
  - name: string          # Method name
    description: string   # Optional: Human-readable description
    args:                 # Optional: List of arguments
      - name: string
        type: string      # Argument type (see below)
        description: string
        default: value    # Optional: Default value
        enums:            # Optional: Enumeration values
          - name: string
            value: integer
            description: string
    returns:              # Optional: Return values (same format as args)
      - name: string
        type: string
        description: string
```

## Argument Types

| Type | Description             | Python Type |
| ---- | ----------------------- | ----------- |
| `B`  | Unsigned 8-bit integer  | `int`       |
| `H`  | Unsigned 16-bit integer | `int`       |
| `I`  | Unsigned 32-bit integer | `int`       |
| `Q`  | Unsigned 64-bit integer | `int`       |
| `b`  | Signed 8-bit integer    | `int`       |
| `h`  | Signed 16-bit integer   | `int`       |
| `i`  | Signed 32-bit integer   | `int`       |
| `q`  | Signed 64-bit integer   | `int`       |
| `e`  | 16-bit float            | `float`     |
| `f`  | 32-bit float            | `float`     |
| `d`  | 64-bit float            | `float`     |
| `?`  | Boolean                 | `bool`      |
| `s`  | Byte string             | `bytes`     |

These type codes follow Python's `struct` module conventions. Arguments without a `type` field accept `Any`.

## Example Configuration

```yaml
name: MyAPI
prefix: ""

methods:
  - name: get_status
    description: "Get the current device status"
    returns:
      - name: status
        type: B
        description: "Status code"
        enums:
          - { name: OK, value: 0, description: "Operation successful" }
          - { name: BUSY, value: 1, description: "Device is busy" }
          - { name: ERROR, value: 2, description: "An error occurred" }

  - name: set_value
    description: "Set a value on the device"
    args:
      - name: channel
        type: B
        description: "Target channel"
      - name: value
        type: f
        description: "Value to set"
    returns:
      - name: success
        type: "?"
        description: "Whether the operation succeeded"

  - name: ping
    description: "Ping the device"
```

## Generated Outputs

### Python Module (`--py`)

```bash
embgen jsonrpc config.yml -o output/ --py
```

Generates a Python class with typed methods that produce `Method` instances for use with a JSON-RPC client:

```python
# myapi.py - Generated by embgen
from enum import Enum
from typing import Any, Optional, Callable
from dataclasses import dataclass

@dataclass
class Method:
    method: str
    params: Optional[dict[str, Any]] = None

class MyapiMethods:
    def __init__(self, add_callback: Optional[Callable[[Method], None]] = None):
        self._add_callback = add_callback

    class GetStatusStatus(Enum):
        OK = 0
        BUSY = 1
        ERROR = 2

    def get_status(self) -> Method:
        """Create a get_status command instance"""
        ...

    def set_value(self, channel: int, value: float) -> Method:
        """Create a set_value command instance"""
        ...

    def ping(self) -> Method:
        """Create a ping command instance"""
        ...

    def custom(self, method: str, **params) -> Method:
        """Create a custom command with arbitrary method name and parameters"""
        ...
```

### Markdown Documentation (`--md`)

```bash
embgen jsonrpc config.yml -o output/ --md
```

Generates human-readable documentation with:

- Method summary table
- Detailed argument and return value documentation
- Enumeration value tables

## CLI Usage

```bash
# Generate Python module only
embgen jsonrpc config.yml -o output/ --py

# Generate all formats
embgen jsonrpc config.yml -o output/ --py --md

# With debug output
embgen -d jsonrpc config.yml -o output/ --py
```

## Python API Usage

```python
from pathlib import Path
from embgen.discovery import discover_domains
from embgen.generator import CodeGenerator

domains = discover_domains()
code_gen = CodeGenerator(domains["jsonrpc"], Path("output"))

templates = {"py": "template.py.j2", "md": "template.md.j2"}
code_gen.generate_from_file(Path("api.yml"), templates)
```

## Auto-Detection

The JSON-RPC domain is detected when the YAML file contains a `methods` key:

```yaml
# Detected as JSON-RPC domain
name: MyAPI
methods:
  - name: ping
```
